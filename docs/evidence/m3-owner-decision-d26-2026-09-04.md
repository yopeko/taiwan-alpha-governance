## 0. 要解的空缺

M0 §8 自 v1.0.0 起寫著：

> 所有候選必須在相同成本模型下比較並**通過**至少 2 倍成本壓力後，才可由 `research` 申請進入 `validated`。

**而「通過」從來沒有被定義。**

它沒有現形，是因為**壓力測試從來沒有被執行過**——`--cost-multiplier` 於 2026-09-03 才建成，2026-09-04 才第一次跑。一句沒有人執行的要求，它的歧義不會被發現。

## 1. 決定：定義如下

**通過 2 倍成本壓力 = 在 2× 乘數下，候選的淨報酬仍勝過隨機同池選股分佈的中位數，且仍勝過與其基礎一致的市場基準（未還原價格指數）。**

### 1.1 為什麼是這兩個，不是別的

考慮過三種讀法：

| 讀法 | 判準 | 問題 |
|---|---|---|
| 甲 | 仍為正報酬 | 一個在多頭市場正報酬但輸給指數的策略「通過」了，那個門檻沒有意義 |
| **乙（採用）** | **仍勝過對照組** | — |
| 丙 | 結論不翻轉 | 與乙在實務上重合，但「結論」本身需要定義，等於把問題往後推一層 |

而乙自己還有一個歧義：**「對照組」指哪一個。** §9.1 的最低比較組有七項，而它們在成本壓力下的可比性不同：

| 對照 | 能不能被成本壓力壓 | 採為判準 |
|---|---|---|
| **隨機同池選股** | **能**——淨額、同名額、同乘數 | **是** |
| **未還原價格指數** | 不能（公布的不是交易的）| **是**，見 §1.2 |
| 現金 | 沒有意義（名目 0%，不交易）| 否 |
| 報酬指數 | 不能，**且含息而策略不含** | 否 |
| 臺灣50 | 不能，**且是權值股組合非合格池** | 否 |
| 合格池等權 | 不能（兩千檔在 M0 規模不可執行）| 否 |
| champion | 不存在（沒有東西是 `validated`）| 不適用 |

### 1.2 為什麼價格指數是判準而報酬指數不是

研究資料集用**官方未還原收盤價**，所以策略**收不到股息**。

- 對**價格指數**比：兩邊都不含股息，**基礎一致**
- 對**報酬指數**比：要求策略贏過一個它結構上拿不到的東西

**報酬指數與臺灣50 仍必須依 §9.1 並排呈報**，只是不作為判準。並排的用途是讓讀者看見市場真正付了多少；判準的用途是問候選有沒有加值。**那是兩件事。**

### 1.3 隨機組必須被同樣壓

**只壓候選不壓對照，等於拿候選去比一個比較容易的世界。**

本次執行因此把 20 個隨機種子也在 2× 下跑了一遍。

## 2. 第一次執行的結果

`momentum-12-1`、`rank-only`、`lookback=20`、`stop_pct=0.08`、參考衡量規模、參與率 0.01、開發側 1,458 場次、**修正後的成交模型**。

| 成本乘數 | 報酬 | 最大回撤 | 完成交易 |
|---:|---:|---:|---:|
| 1× | +239.21% | 57.99% | 281 |
| 1.5× | +211.24% | 59.22% | 285 |
| **2×** | **+202.17%** | 61.79% | 288 |
| 3× | +171.34% | 64.44% | 274 |

同一窗口的對照：

| 對照 | 報酬 | 基礎 |
|---|---:|---|
| 隨機同池 中位（**2× 壓力**）| **−17.79%** | 淨 |
| 隨機同池 範圍（2×）| −40.45% ~ +12.31% | 淨 |
| 現金 | +0.00% | 名目 |
| 合格池等權 | +123.98% | 毛 |
| **TAIEX 價格指數** | **+141.10%** | 毛 |
| 臺灣50 價格指數 | +171.61% | 毛 |
| TAIEX 報酬指數 | +198.63% | 毛 |
| 臺灣50 報酬指數 | +234.92% | 毛 |

### 判定

| 判準 | 門檻 | 結果 | |
|---|---:|---:|---|
| 勝過隨機同池中位（2×）| −17.79% | +202.17% | ✅ **勝 220pp，20/20** |
| 勝過未還原價格指數 | +141.10% | +202.17% | ✅ **勝 61pp** |

**通過。**

### 而它輸給一個並排的欄位，那件事要寫下來

**臺灣50報酬指數 +234.92%，動能 +202.17%，差 32.75pp。**

依本決定那不構成不通過（含息、且是權值股組合）。**但它被呈報，而不是被略過**——一個只列出候選贏的那些欄位的報告，就是 §9.1 存在要防的東西。

## 3. 這不是「動能通過了驗證」

**成本壓力只是申請 `validated` 的前置條件之一。**

[對照計畫 001](m7-control-plan-001-random-selection-2026-09-01.md) 的**條件三（回撤）在 2026-09-01 就沒有通過**，而[停損成交價修正](m6-gapped-stop-fill-2026-09-04.md)後回撤更差（54.06% → 57.99%，2× 下 61.79%）。M0 §8.1 的硬停止門檻是 **8%**。

**動能仍然不是 `validated`，也不接近。**

## 4. 一併追認：候選報告契約 v1.3.0

`§2.1` 新增五個必填欄位——M0 §9.1 從第一版就要求、而**沒有任何一份報告帶過**的那三欄（現金、指數、等權池），加上一個 `benchmark_basis`。

**`benchmark_basis` 恆為 `gross` 且必填**，因為候選的 `return_pct` 是淨額。一份把淨額與毛額並排而不說的報告，是在讓讀者自己去假設——而 2026-09-03 實測那個假設值 **50 個百分點**，且朝美化選股的方向。

**指數表缺席時該欄為 null 並在 manifest 記錄原因，不是把欄位拿掉。**

## 5. 沒有決定的

- **沒有把動能升為 `validated`。** 見 §3。
- **沒有為其他候選跑壓力測試。** 本次只跑了 `momentum-12-1`。候選 006 的四臂、診斷 004 的七格都還沒有。
- **沒有處理「champion 不存在」。** §9.1 要求那一欄，而它會一直是空的直到有東西通過。
