# 候選計畫 005：把唯一有排序能力的東西裝上唯一有效的進場規則（2026-08-28）

**狀態：`planned`。本文件必須在任何一次執行之前提交。**

依[對照比較契約](../contracts/control-comparison-contract.md) §4 與[試驗登錄契約](../contracts/trial-ledger-contract.md)。

**此刻沒有任何結果存在。**

## 0. 為什麼是這個組合，以及為什麼它不是「再換一個常數」

前四份計畫的形狀都是「換掉一個沒被論證過的常數」。本份不是——**兩個零件都已經被單獨量過了。**

| 零件 | 已知的事 | 出處 |
|---|---|---|
| `inverse-volatility-60` 排序 | Rank IC **六年逐年全正**、IC 命中率 66.7%、分位中位數完全單調 | [量測 001](rank-quality-001-2026-08-28.md) |
| rank-only 進場 | 對上突破進場，三條門檻在兩個參與率下**全部通過** | [候選 003](m7-candidate-003-result-2026-08-28.md) |

**而這兩個從來沒有裝在一起跑過。**

已跑過的組合是：rank-only + 動能（003，通過門檻但排序 IC 為零）、突破 + 低波動（比較 001，誰都沒勝出）。**唯一沒跑的，正好是兩個各自表現最好的零件的組合。**

### 歸因不會像先前那樣糊掉

004b 的教訓是規格與意圖之間的落差比效應本身還大。本份不同：**兩個零件的個別效果都已量過**，所以

- 若它通過，可以問「是否超過兩個零件各自貢獻的簡單相加」；
- 若它沒通過，那本身就是資訊——**兩個各自有效的東西裝起來未必有效**，而這個窗口裡有一個具體的機制解釋它（見 §4）。

## 1. 候選定義

| | 候選 A（對照）| 候選 B |
|---|---|---|
| 候選 id | `rank-only-momentum` | `rank-only-inverse-vol` |
| 進場 | rank-only，每 21 場次持有前 10 | 同左 |
| **排序** | **`momentum-12-1`** | **`inverse-volatility-60`** |
| 停損 | 固定 8% | 同左 |
| 股票池 | `all` | 同左 |

**唯一的差異是排序函式。** 對照組 A 就是候選 003 的 B，也就是本專案目前唯一通過門檻的東西——**用現有最好的當對照，不用探針**。

## 2. 預期：有一個方向，而且它有可能被否證

**這次有預期，而且它預期的是「不會贏」。**

理由是量測 001 已經量到的機制：`inverse-volatility-60` 的分位**中位數**單調上升，**平均**卻單調下降——高波動股的右尾主導平均，而**固定 8% 停損讓每個部位都是 9.35% NAV，等權組合收割的正是平均**。

所以：

> **預期 B 不會通過三條門檻**，因為它的排序優勢在中位數上，而等權組合拿的是平均。

**這個預期若被推翻——B 通過了——那代表量測 001 對「平均與中位數為何相反」的解釋是錯的，或至少不完整。** 那比 B 通過本身更值得知道。

上一份計畫（004b）明確不設預期，因為它的預期已被事前檢查消耗。本份的預期來自一個**已發表的量測**，不是來自對本次資料的預覽。

## 3. 什麼結果會被算作「沒有幫助」

判定只看**參考衡量規模**（ADR-0002 決策 1）。

**「B 勝過 A」須同時滿足：**

1. 兩個參與率下，B 的窗口內報酬皆高於 A；且
2. 差距皆至少 **5 個百分點**；且
3. B 的窗口內最大回撤不高於 A 的 **1.5 倍**。

**與計畫 001、003、004、004b 完全相同。五份共用同一組門檻。**

### 必須呈報但不參與判定的兩項

**一、部位大小分布與總曝險。** 004b 的教訓：一個曝險差五倍的比較測到的是曝險不是設計。兩者都用固定 8% 停損，所以曝險應當接近——**若不接近，這次比較同樣有問題，而那要在讀報酬之前被看見。**

**二、B 的報酬／回撤比。** 004b 時我把它記下來卻不使用，因為它不在門檻裡。**這次事前寫進來，所以它可以被使用**——但只作為呈報項，不改變 §3 的判定。

## 4. 若 B 沒通過，最可能的解釋已經寫在這裡

不是「低波動無效」。量測 001 顯示它的 IC 六年全正。

而是**等權組合與「排序在中位數上有效」不相容**：組合報酬由平均驅動，而低波動排序刻意避開了貢獻平均的那條右尾。

若這是真的，那麼下一步不是換排序，是換**組合的權重或持有檔數**——而 004b 已經示範了那條路要怎麼走才不會測到別的東西。
