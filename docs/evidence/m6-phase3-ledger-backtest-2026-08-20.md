# M6 Phase 3：帳本驅動的回測（2026-08-20）

## 結論

M3 的凍結資料集、M4 的規則與 M5 的帳本第一次被串起來逐日跑完 382 個交易日。

**在這之前,倉庫裡的每一個數字都來自一張表;這是第一個來自模擬帳戶的數字。**

過程中驅動器抓到兩個真實缺陷,其中一個嚴重——**部分成交會留下永遠賣不掉的部位**,靜默地把完成交易由 86 筆砍到 5 筆。

## 1. 每個交易日的順序

```
1. 交割今天到期的款項
2. 標記帳面 —— NAV 與回撤在做任何決定之前先量測
3. 先出場 —— 出場會釋放名額與資金
4. 再進場 —— 依 M0 風險政策定量，不是依帳上剩多少錢
```

**訊號用 S 日收盤計算,委託在 S+1 日送出。** 同一根 K 棒決策又成交,等於用決策當下不可能知道的價格交易——這是回測最古老的錯誤,也是整座倉庫存在的理由。

成交一律經過 `Ledger.execute`,由資料集記錄的市場狀態(可交易性、漲跌停、流動性)決定結果。

## 2. 探針策略：刻意平凡

`close-above-n-session-high`,單一參數,20 日暖身。

選它的兩個理由:

- **只需 20 日暖身**,可用 382 日中的絕大部分,不像 52 週規則只剩 132 日
- **只有一個參數**,結果不可能是搜尋出來的

**它是管線的探針,不是提案。** 存在的目的是讓失敗可以歸因於水管,而不是歸因於一個沒人能在腦中完整持有的型態偵測器。

## 3. 兩個被抓到的缺陷

### 3.1 規劃器與帳本互相矛盾（156 次）

一百萬情境出現 156 筆 `entry:invalid-lot-size`。

`plan_position()` 依風險算出例如 1,234 股——兩張整股加 234 股零股。單一委託不可能是這個數量,`Ledger.execute` 因此拒絕。**訊號就這樣消失了,而且沒有任何一道上限拒絕過它。**

修法:`plan_position()` 在套完所有上限後向下對齊到合法股數。向下取整,所以剛套用的每一道上限依然成立。

### 3.2 部分成交留下賣不掉的部位（嚴重）

修好 3.1 之後,一百萬情境冒出 **640 筆 `exit:invalid-lot-size`**,完成交易從 66 掉到 **5**。

原因:進場委託 2,000 股(合法整股),但流動性上限只成交 1,437 股。**1,437 是混合股數,單一賣單永遠被拒——那個部位被卡死到回測結束。**

這不是模擬的瑕疵,是真實的執行結構。台灣的作法是拆成兩筆:1,000 股走一般交易,437 股走零股盤。

修法在驅動器(這是執行層的事,帳本拒絕混合單是對的):賣出時依 `lot_legs()` 拆成整股腿與零股腿。

修正後完成交易 **5 → 86**。

**這兩個缺陷單看程式碼都看不出來。** 它們只有在一個真的走完日曆、真的處理部分成交的驅動器裡才會現身——這正是 Phase 3 的價值。

## 4. 結果

| 資金 | 完成交易 | 期末報酬 | 最大回撤 | 帳本分錄 |
|---|---:|---:|---:|---:|
| NT$10,000 | 49 | **−1.85%** | 10.91% | 245 |
| NT$1,000,000 | 86 | **−2.00%** | 3.28% | 344 |

探針策略兩個規模都小賠。**這是預期中的,而且不是重點。**

### 重點在成本的規模效應

以 NT$10,000 的那一輪拆解:

| 項目 | 金額 |
|---|---:|
| 毛損益（僅計價差） | +1,732 |
| **費用與稅** | **−1,917** |
| 淨損益 | **−185** |

**毛利有 17.3%(佔期初資金),被 19.2% 的成本完全吃掉。**

同一策略在一百萬下成本只佔期初資金的 2.17%。**九倍差距。**

這把 Phase 0 用試算表得到的結論,在一條完整的帳本管線上重現了一次。

## 5. 被拒絕的委託比成交更有資訊量

NT$10,000 那一輪:

| 拒絕理由 | 次數 |
|---|---:|
| `entry:position-slots-full` | 52,533 |
| `entry:opened-below-stop` | 10 |
| `entry:not-tradable-restricted` | 2 |

五萬多次「名額已滿」不是缺陷,是 **M0 只給兩個名額**的直接後果。它說明的是:**這個策略產生的訊號量,遠超過這個帳戶能承接的量**,因此實際成交的是哪兩筆,幾乎由先後順序決定,而不是由訊號品質決定。

一個只能接兩檔的帳戶配上一個每天產生數十個訊號的策略,**選股邏輯的作用被名額稀釋掉了**。這是策略與資金規模不匹配的具體證據,而它不會出現在任何一張報酬率表上。

## 6. 記錄下來的假設

| 假設 | 值 | 理由 |
|---|---|---|
| 流動性參與率 | 當日成交量的 **1%** | M0 禁止假設必然成交,這是取代「一定買得到」的那個假設 |
| 訊號與成交 | S 日收盤決策,S+1 日開盤成交 | 不得用決策當下不知道的價格 |
| 同日觸及停損與停利 | **假設停損先到** | 日線無法辨別時序,此假設偏向不利於帳戶 |
| 停牌中持股的標價 | 沿用進場價 | 帳本拒絕為無報價的部位估值 |

全部寫進輸出的 manifest。
