## 1. 判定：通過，三條門檻全部滿足

參考衡量規模，共同窗口 1,177 場次（2020-02-25 → 2024-12-19）。A 為突破進場，B 為 rank-only，兩者排序函式相同。

| | 參與率 0.01 | 參與率 0.001 |
|---|---:|---:|
| A（突破）報酬 | +2.49% | +25.34% |
| **B（rank-only）報酬** | **+163.20%** | **+43.41%** |
| B − A | **+160.70 點** | **+18.07 點** |
| A 回撤 | 61.97% | 44.91% |
| B 回撤 | 54.06% | 55.95% |
| B 回撤 ÷ A 回撤 | 0.87× | 1.25× |

| 條件 | 0.01 | 0.001 |
|---|---|---|
| 一：B 報酬高於 A | ✅ | ✅ |
| 二：差距 ≥ 5 點 | ✅ | ✅ |
| 三：B 回撤 ≤ A 的 1.5 倍 | ✅ | ✅ |

**這是本專案第一次有候選通過預先登錄的門檻。** 比較 001 的兩個候選誰都沒有通過。

## 2. 我寫的「可被否證的預期」被否證了，原因是我寫錯了基準

計畫 §2 寫：

> 月再平衡的週轉應顯著低於突破進場。M6.2 量到突破的換入是 8.72 檔／場次；月再平衡的上限是 0.48 檔／場次，**低一個數量級以上**。

實測：

| 參與率 | 突破 | rank-only | 倍數 |
|---|---:|---:|---:|
| 0.01 | 0.761 筆／場次 | 0.242 | **3.1×** |
| 0.001 | 0.990 筆／場次 | 0.278 | **3.6×** |

**週轉確實顯著較低，但不是一個數量級。**

原因是我拿錯了比較基準：**8.72 檔／場次是 [M6.2](m6-2-rotation-feasibility-2026-08-26.md) 全面重排設計的換入率，不是這個突破候選的**。突破候選的實際完成交易率是 0.76–0.99 筆／場次，而我用一個別的設計的數字當作它的值。

一個對錯基準寫下的可否證預期，並沒有比沒有預期好多少。**這是計畫 §2 的缺陷，不是結果的缺陷**，而它讓「預期被否證」這件事失去了它本來該有的資訊量。

記在這裡，因為下一份計畫要避免它：**預期要對著實際對照組寫，不是對著一個記得的數字。**

## 3. 通過了，但這些必須一起讀

### 3.1 兩個參與率的差距相差九倍

+160.70 點對 +18.07 點。兩者都通過門檻，方向一致，但**幅度對一個沒有證據的假設極度敏感**。

依[對照比較契約](../contracts/control-comparison-contract.md) §3，四組必須一起讀，而這個不一致本身就是內容：**「rank-only 比突破好」是穩健的，「好多少」不是。**

### 3.2 窗口含一段極強的多頭

共同窗口是 2020-02-25 至 2024-12-19，其中 2020–2021 是台股史上最強的一段多頭之一。**動能策略在多頭市場表現好是它已知的性質**，不是這次的發現。

一個窗口、一次執行，不主張任何跨市況的結論。

### 3.3 選項乙的代價在這次特別明顯

`open_positions_at_window_start`：**A 帶著 10 檔部位進入比較起點，B 帶著 0 檔。**

共同窗口的起點由 B 決定（它需要 252 場次熱身加再平衡對齊），而 A 從 2020-01 就在交易。兩個帳戶在比較的第一天狀態不同——報酬已依窗口起點 NAV 重算，但**A 是滿倉進場、B 是空手進場**，這在窗口開頭的行為不對等。

選項甲（兩邊都重跑截斷窗口）不會有這個問題。這是乙在 2026-08-27 被選擇時就記下的代價，現在它有了具體數字。

### 3.4 m0 規模這次方向一致，但仍不可用

m0 規模下 B 也大幅優於 A（+38.61% 對 −47.09%）。與比較 001 兩個規模方向相反不同，這次一致。

**但依 ADR-0002 決策 1 仍不得作為策略證據**，且共同窗口只有 239 與 187 場次。

## 4. 能與不能支撐什麼

### 可以

- 在開發區的共同窗口內、在兩個參與率下，**rank-only 進場依預先登錄的門檻勝過突破進場**，排序函式相同。
- 週轉顯著較低（3.1–3.6 倍），但**不是一個數量級**。

### 不可以

- **不能說 rank-only 在台股有效。** 一個窗口、一次執行、一段強多頭。
- **不能用 +163.20% 這個數字。** 同一組條件換一個成交假設是 +43.41%，兩者都通過而幅度差九倍。
- **不能把這當成 `validated`。** M0 §9 的軌道要求的不是通過一次比較，而封存區未開封。
- **不能因為通過就回頭調參。** 巢狀驗證契約 §3.3 的精神同樣適用。
