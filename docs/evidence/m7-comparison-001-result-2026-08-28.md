## 1. 判定：兩個都沒有通過

計畫 §3 的三條門檻，套用在參考衡量規模（ADR-0002 決策 1 禁止用 m0 規模的報酬當策略證據）：

| | 參與率 0.01 | 參與率 0.001 |
|---|---|---|
| 共同窗口 | 1,197 場次 | 1,202 場次 |
| A `momentum-12-1` 報酬 | **+1.08%** | **+27.66%** |
| B `inverse-volatility-60` 報酬 | −6.84% | −27.35% |
| B − A | −7.92 點 | −55.01 點 |
| A 回撤 | 61.97% | 44.91% |
| B 回撤 | **14.05%** | **28.16%** |

**B 沒有勝出。** 條件一（兩個參與率下 B 報酬皆高於 A）在兩處皆不成立。

**A 也沒有勝出。** 把三條門檻的角色對調：A 的報酬確實在兩處皆高於 B，且差距皆超過 5 點——但條件三不成立。A 的回撤是 B 的 **4.41 倍**與 **1.59 倍**，兩者都超過 1.5 倍上限。

**所以這次比較的登錄結果是：誰都沒有勝出。**

### 這正是條件三存在的理由

如果只看報酬，A 贏 7.9 點與 55.0 點，看起來是明確的結論。條件三擋下它，而擋得對——**A 的權益曲線在同一段窗口內掉過將近三分之二**，那不是比較好的排序，那是比較大的曝險。

這條門檻在 2026-08-28 11:49 寫下，那時沒有任何結果存在。若它是在看到 61.97% 之後才被加進去，它一文不值。

## 2. 兩個規模給出相反的答案

| m0 執行規模 | 參與率 0.01 | 參與率 0.001 |
|---|---|---|
| 共同窗口 | 41 場次 | 35 場次 |
| A 報酬 | −27.93% | −25.29% |
| B 報酬 | **−19.83%** | **−17.44%** |

在 m0 規模，B 兩處都比 A 好 8 點左右，回撤也較低。**與參考規模的方向相反。**

依 ADR-0002 決策 1，這兩列不得作為策略證據，所以它們沒有進入判定。但它們仍要被讀：**同一組候選、同一段資料，換一個資金規模就換一個答案**，而那是這份 ADR 從頭到尾在講的事。

也要注意共同窗口只有 41 與 35 個場次。m0 規模的帳戶很早就停止交易，共同窗口取交集因此縮成兩個月不到。這兩列即使可以用，樣本也不足以下任何結論。

## 3. 低波動排序做到了文獻說它會做的事，只是不是報酬

`inverse-volatility-60` 在參考規模的回撤是 14.05% 對 61.97%，以及 28.16% 對 44.91%。**兩處都遠比動能平穩。**

低波動文獻主張的正是這件事——低波動股票的報酬相對其風險偏高——而這次的資料與那個方向一致：B 用遠小的波動換到較差的報酬。

**但不能把這句話說成「低波動在台股有效」。** 這裡測的是「60 日低波動排序 + 20 日突破進場 + 8% 停損 + 20 場次持有上限 + M0 §8 風險政策」這個組合在開發區的一次跑。計畫 §1 已經預先寫下這一點：文獻沒有說「剛創 20 日新高的股票之中波動低的比較好」。

## 4. 熱身較短確實把窗口拉長了

| | 共同窗口（參考規模）|
|---|---:|
| 比較 000（動能 對 未排序）| 1,584 場次 |
| 比較 000（動能 對 未排序，m0）| **37 場次** |
| 比較 001（動能 對 低波動）| 1,197 場次 |
| 比較 001（動能 對 低波動，m0）| **41 場次** |

參考規模的窗口變短是因為這次跑在開發區（到 2024-12-31 為止），不是因為候選。m0 規模仍然只有 41 場次——**那個限制來自帳戶太早停止交易，不是來自熱身**，所以換一個熱身較短的候選並沒有解決它。

我在挑選候選 B 時把「熱身短、共同窗口會長很多」寫成三個理由之一。就 m0 規模而言，**那個理由沒有兌現**。

## 5. 這次比較能與不能支撐什麼

### 可以

- 在開發區的共同窗口內、在兩個參與率下，兩個候選依預先登錄的門檻誰都沒有勝出。
- 低波動排序在同一組進場規則下產生遠低的回撤與較差的報酬。
- 對照比較契約的格式在第二次使用時運作正常，且條件三擋下了一個只看報酬就會成立的結論。

### 不可以

- **不能宣告動能勝出。** 它的報酬較高，但它的回撤超過預先登錄的上限。
- **不能宣告低波動無效。** 這是一次跑、一個窗口、一個組合。
- **不能因為門檻擋下結論就調整門檻。** 計畫 §3 已寫明：要改門檻須另寫一份新計畫並說明為什麼舊的不適用，而那份說明會與結果同時被讀。
- **不能用 m0 規模的兩列。** ADR-0002 決策 1。
- **不能主張統計顯著性。**
