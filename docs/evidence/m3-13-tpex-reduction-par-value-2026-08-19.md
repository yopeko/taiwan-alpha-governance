# M3.13：上櫃減資與變更股票面額（2026-08-19）

## 結論

上櫃的減資與變更股票面額已進入 canonical 表：**22 筆停牌事件，全數 `publisher-exact`**。

全期間超過 ±10% 的 269 筆單日變動中，未解釋者由 92 筆降至 **73 筆**；**上櫃不再有任何跌幅超過 50% 的未解釋變動**（原有 4 筆）。

## 1. 先確認一件事：櫃買沒有歷史表

上市那套（TWTAUU／TWTB8U）在櫃買**不存在對等的歷史來源**。四個對應端點全部實測，全部只服務未來數日：

| 端點 | 頁面 | 行為 |
|---|---|---|
| `bulletin/revivt` | 減資恢復交易參考價 | 忽略 `date`，一律回傳 `20260820~20260825` |
| `bulletin/decap` | 減資預告表 | 帶日期參數即 `參數錯誤`；不帶則回傳當下待執行者 |
| `bulletin/pvChgAnn` | 變更股票面額預告表 | 忽略日期 |
| `bulletin/pvChgRslt` | 變更股票面額恢復買賣參考價 | 忽略 `date`，一律回傳 `20260820~20260831` |

這正是來源註冊表早已記錄的 TPEx 陷阱——**對無法辨識的參數不報錯，安靜地回傳當期資料**。回應中的 `date` 欄位會誠實echo它實際服務的區間，`echoed_range_matches()` 就是為此而寫。

櫃買的 OpenAPI 目錄（225 個端點）同樣沒有：以 減資／面額／分割／恢復買賣／參考價 逐一搜尋，只命中除權除息兩張表。

**結論不是「還沒找到」，而是「不存在」。**

## 2. 歷史只在市場公告檔案裡

`bulletin/announcement`——公告查詢，這是櫃買唯一吃真實日期區間的公告來源。

| 項目 | 值 |
|---|---|
| 日期格式 | **西元 `YYYY/MM/DD`**。ROC 與 `YYYYMMDD` 皆回 `日期參數錯誤` |
| 類別 | `cate=2`（除權、除息、增資、減資、換股）|
| 全期間（2025-01-01 ~ 2026-08-03）| **47 則公告**，一次請求即可取得 |

類別清單是查詢頁自己的 `<select>` 選項，非自行假設。

每則公告的詳細文件（`bulletin/annDetail`）以編號分項敘明事實：

```
一、停止股東名簿記載變更之事由：股票面額由每股5元變更為2.5元，全面換發股票。
二、換發內容：…每1股換發新股票2股。
三、暫停股票櫃檯買賣日期：115年2月25日至115年3月6日。
…
七、公司新股票開始櫃檯買賣日期：115年3月9日。
```

停牌區間、恢復日、換股比例、面額前後全在裡面，**而且公告本身帶發文日期**。

## 3. 意外的結果：上櫃的證據等級比上市高

| | 上市面額變更（TWTB8U）| 上櫃面額變更（公告檔案）|
|---|---|---|
| 停牌區間 | 有 | 有 |
| 恢復買賣參考價 | **有** | 無 |
| 漲跌停 | **有** | 無 |
| 公告日期 | **無** | **有** |
| `availability_basis` | `unknown-blocked` | **`publisher-exact`** |

上市有價格、沒日期；上櫃有日期、沒價格。**兩者恰好互補，而且缺的那一半在各自的市場都取不到。**

因此 `adjustment_evidence` 新增第四個值 `publisher-exchange-ratio-only`：上櫃的列只帶換股比例，而**換股比例不足以決定交易所實際採用的參考價**。讓它顯性宣告，好過留四個 null 讓讀者自行猜測。

## 4. 自由文字的解析紀律

公告是散文，但格式高度固定。每個事實只以**它自己的分項標題**為錨點比對，比不到就留 null，絕不從鄰近文字刮取。

第一版有兩個錯誤，都由實際文本發現：

| 錯誤 | 原因 | 修正 |
|---|---|---|
| 22 則分類為面額／減資卻無停牌區間 | 只認 `證券代號`，但公告混用 `股票代號`；停牌標題有 `暫停…日期` 與 `停止…期間` 兩種寫法 | 兩者皆接受，完整解析由 9 筆增為 22 筆 |
| 撤回公告被歸為面額變更 | 分類條件是 `"面額" in 文本`，而減資公告會順帶提到「每股面額新台幣10元」 | 改以 `面額變更`／`變更股票面額` 為條件，並新增 `withdrawn` 類別。**撤回是一件沒有發生的事，靜默歸類成已發生是最糟的失效方式** |

修正後：面額變更 12、減資 16、撤回 3、非本類 16。

## 5. 交叉驗證

停牌日期解析自公告散文；價格來自每日行情表。兩者不共用任何程式路徑。

**兩市場合計 47 段停牌區間、46 段落在已擷取的交易日內，區間內報價筆數為 0。**

包含全部 22 段由自由文字解析而來的上櫃停牌。若正則抓錯了日期，幾乎不可能剛好每一段都落在真實的無報價區間上。

## 6. 一個被推翻的推測

[M3.11 §6](m3-11-tpex-actions-promotion-2026-08-19.md) 推測上櫃 38 筆**上漲**異常（最大 +266%）「形態符合新上櫃前五日無漲跌幅限制」，並註明未經驗證。

**該推測是錯的。** 其中 8291、4950、4530、5301、4806 等皆為**減資**——減資銷除股份會使每股價格上升，大幅上漲正是它的特徵。已在本次一併解釋。

原文已標註未驗證，但推測寫進文件就會被當成結論讀，這裡明確更正。
