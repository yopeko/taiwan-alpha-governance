# M3.11：TPEx 公司行動晉升 canonical 表（2026-08-19）

## 結論

M3.8 記錄的例外 #2「TPEx 公司行動未晉升 canonical 表」**已解除**，strict xfail 轉為實測通過。

`corporate_actions_pit` 由 1,670 列（僅上市）增為 **3,814 列**（上市 1,665 + 上櫃 2,149）。全期間單日超過 ±10% 的價格變動中，未解釋者由 **171 筆降至 97 筆**。

## 1. 資料早就抓完了，卡在沒有搬運

M3.1f 已擷取 2,698 筆 MOPS listing 與 2,314 筆 detail 觀測，全數進入 staging 並完成 parse。`build_actions()` 只讀 `TWSE-ACTIONS-HIST` 一個來源，其餘留在 staging。

## 2. 兩個市場的來源結構相反

| | TWSE | TPEx |
|---|---|---|
| 端點 | TWT49U，吃日期區間 | 無區間端點，只能逐檔逐年查 MOPS |
| 一次回傳 | 一整張表 | 一份公告文件 |
| 除權息參考價 | **有** | 無 |
| 現金股利金額 | 有 | **有** |
| 公告日期 | **無** | **有** |

最後一列是關鍵：**端點較差的那個市場，反而有較好的來源可信度**。TPEx 的每一筆行動都是以「公告」為單位取得的，公告日期隨之而來；TWSE 的 TWT49U 是一張結果表，完全不提供公告日期（M3.9 另以 TEJ 補上）。

因此 2,149 筆 TPEx 全部是 `publisher-exact`，1,665 筆 TWSE 全部是 `first-observed-only`。

## 3. 公告日期從 logical_period 取回

TPEx detail 文件本身**只有除權息日與金額，沒有公告日期**。公告日期存在於該 observation 的 `logical_period`：

```
company:TPEX:1240:announced:2024-08-14
```

這是它被擷取時的定址鍵，來自 listing 的 `announced_at`。與減資詳細資料的作法一致：請求鍵回讀自 observation manifest，不重新推導，因此解析出的列**只可能帶著當初真正請求的那個鍵**。

同時檢查文件內的代號與 period 中的代號一致，不一致即跳過——否則會把甲公司的股利掛到乙公司身上。

## 4. 補回先前被丟棄的欄位

原 `build_actions()` 只保留參考價與前收盤，**把 `action_type`、`cash_dividend`、`stock_dividend_ratio`、`adjustment_factor` 全部丟掉**，canonical 表的資訊比 staging 少。

這次一併補回。對 TPEx 而言這不是加值而是必要——MOPS 不提供參考價，若不保留股利金額，TPEx 的列除了一個日期之外什麼都沒有，無法解釋任何價格變動。

新增 `adjustment_evidence` 的第二個值 `publisher-dividend-amount-only`，讓調整價格的人知道這一列靠的是哪一種證據。**股利金額不等於參考價**：交易所實際採用的參考價還牽涉進位與其他配發項目，兩者不可混為一談。

## 5. 去重與修訂的分界

去重鍵刻意包含金額：

```python
CONTENT_KEY = ("market", "symbol", "effective_date",
               "action_type", "cash_dividend", "stock_dividend_ratio")
```

| 情況 | 筆數 | 處置 |
|---|---:|---|
| 同一公告經多張 listing 重複取得，內容相同 | 148 | 併為一列，**取最早的公告日期** |
| 同一除權息日、金額不同 | 23 | **兩列都保留**，這是修訂 |
| TWSE 跨月區間重疊產生的重複 | 5 | 併為一列 |

取最早而非最晚：同一內容若被公告兩次，它在第一次公告時就已可知。取最晚會宣稱它比實際更晚才可用。

修訂列以 `revision_ordinal` 依公告日期編號。刪掉其中一列會讓 as-of 查詢在不同 cutoff 下得到錯誤答案——查詢者應取「公告日期在自己 cutoff 之內、序號最大」的那一列。

那 5 筆 TWSE 重複全部是 2026-07-31 的事件，出現在兩個不同 snapshot（跨月區間重疊），內容逐欄相同。與先前在市場狀態表發現的是同一個缺陷。
