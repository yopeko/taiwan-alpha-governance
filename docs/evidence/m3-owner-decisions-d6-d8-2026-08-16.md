### D7：以處置內文回補部分變更交易方法狀態

批准由處置公告的 `處置措施`／`處置內容` 文字判定該證券是否同時被變更交易方法為全額交割。

**範圍限制**：此法**僅能**回補與處置同時發生的變更交易方法。獨立發生的變更交易方法（未伴隨處置者）仍不可得，必須維持 `unknown`。

### D8：批准「價格缺漏推定停牌」政策

批准在缺乏官方停牌歷史來源的情況下，以「該證券在官方當日收盤行情表中不存在」推定其當日未正常交易。

**這是本專案第一次批准以推論補充狀態，因此約束特別嚴格：**

| 約束 | 內容 |
|---|---|
| Evidence state | 固定為 `owner-approved-policy`，**不得**標為 `verified-snapshot` 或任何官方證據等級 |
| Reason code | 必須標記 `suspension-inferred-from-price-absence` |
| 不可逆推 | 出現在行情表**不等於**已知未停牌；只推定單向 |
| 不可用於 formal | 依此推定產生的狀態，在 M7 以後的正式驗證中必須可被單獨排除並重跑 |
| 可追溯 | 每一筆推定必須保留其依據的 session 與觀測 lineage |
| 可撤銷 | 日後若取得官方停牌歷史，官方值一律優先，推定值標記為 superseded |

**Owner 已知悉的取捨**：此推定無法區分「停牌」、「當日無成交」與「尚未上市／已下市」。第三種可由 TEJ 生命週期資料排除，第二種在台股全額交割或極低流動性個股上確實可能發生。因此本政策會**高估**停牌數量，方向上偏保守（把可能可交易者判為不可交易），符合 fail-closed 原則。
