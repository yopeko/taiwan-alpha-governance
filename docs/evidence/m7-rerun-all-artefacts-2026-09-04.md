## 0. 一句話

**沒有任何一份結論被推翻，而每一份的「沒有通過」都變得更明確。**

## 1. 重跑的方法：從產物自己的 manifest 讀組態

每一個參數都從產物的 manifest 讀出來，**不重述**。

一次重述組態的重跑，可以在沒有人注意到的地方與原始執行不同——**而整件事的前提是「唯一改變的是成交模型」**。

## 2. 診斷 003：核心數字幾乎翻倍

純後處理，直接對修正後的產物跑。

| | 修正前 | 修正後 |
|---|---:|---:|
| 停損筆數 | 205 | 198 |
| 劣於設計停損價 | 75.61% | **79.80%** |
| 中位滑價 | −0.80% | **−1.01%** |
| 最差滑價 | −8.70% | **−33.50%** |
| **超額損失（佔期初 NAV）** | **18.86%** | **36.44%** |

診斷 003 的結論是「M0 §8 刻意留的 0.50pp 間隙不存在」。用新的中位滑價重算：

| | 舊 | 新 |
|---|---:|---:|
| 有效停損距離 | 8% + 0.80% = 8.80% | 8% + **1.01%** = **9.01%** |
| × 93.75% 毛曝險 | 8.25% | **8.45%** |
| 超出 8% 硬停止 | 0.25pp | **0.45pp** |

**結論不只成立，而且嚴重一倍。**

## 3. 候選 006：移動停損受的傷害是固定停損的兩倍多

參考規模、參與率 0.01。

| 臂 | 組態 | 報酬 前→後 | 最大回撤 前→後 |
|---|---|---|---|
| A | 固定停損 10 檔 | +266.61% → +239.21% | 54.06% → 57.99% |
| **B** | **移動停損 10 檔** | +89.40% → **+27.60%** | 37.05% → 43.37% |
| C | 固定停損 8 檔 | +141.92% → +99.34% | 51.45% → 56.70% |
| **D** | **移動停損 8 檔** | +88.01% → **+25.84%** | **33.56% → 39.98%** |

報酬損失：**固定停損 −27 至 −43pp，移動停損 −62pp。**

**移動停損會往上棘輪、貼近價格，所以更高比例的觸發是跳空穿過一個很緊的停損。**

候選 006 的宣稱是「移動停損把回撤由 54.06% 降到 33.56% 並保住 +88.01%」。修正後是 **57.99% → 39.98%，保住 +25.84%**——降幅方向仍成立（18pp），但**代價從「幾乎不用錢」變成「吃掉七成報酬」**。

而它的結論「條件一失敗，離 §8.1 的 8% 還有四倍」——現在是**五倍**。

## 4. 診斷 004：那個被禁止採用的「最好一格」，比值掉了七成

| 格（名額-停損）| 回撤 前→後 | 報酬 前→後 | 比值 前→後 |
|---|---|---|---:|
| s2-p002 | 12.10% → **21.55%** | +51.82% → **−2.93%** | 4.28 → **−0.14** |
| s2-p008 | 12.17% → 15.34% | +17.10% → +6.48% | 1.40 → 0.42 |
| **s4-p004** | 12.22% → **20.39%** | +184.14% → +82.17% | **15.07 → 4.03** |
| s4-p008 | 19.79% → 28.33% | +39.16% → +15.99% | 1.98 → 0.56 |
| s6-p006 | 19.56% → 35.92% | +120.22% → +32.55% | 6.15 → 0.91 |
| s6-p008 | 27.98% → 37.53% | +62.65% → +21.70% | 2.24 → 0.58 |
| s8-p008 | 33.56% → 39.98% | +88.01% → +25.84% | 2.62 → 0.65 |

**最低回撤由 12.10% 變成 15.34%，而且換了一格。** 診斷 004 說「不可達 8%」——**現在更不可達**。

**停損越緊被美化越多**：s2-p002（2% 停損）由 +51.82% 變成 **−2.93%**。一個 2% 的停損幾乎總是被跳空穿過，所以「成交在停損價」的假設對它最不成立。

**而診斷 004 明文禁止採用任何一格**，理由是那需要另一份預先登錄的計畫。**本次重跑證明了那個拒絕是對的**：表面最好的 s4-p004 比值 15.07，有將近四分之三是樂觀成交模型造出來的。

## 5. 比較 003 與 005：一個方向反轉，而原因與前面一致

### 5.1 比較 003（窗口不變，1,177 場次）

| | 報酬 前→後 |
|---|---|
| breakout 進場 | +2.49% → **−12.12%** |
| rank-only 進場 | +163.20% → **+145.19%** |

**rank-only 仍然勝出，而且更明確。**

### 5.2 比較 005（窗口由 1,114 腰斬為 568 場次）

| | 報酬 前→後 |
|---|---|
| `momentum-12-1` | +73.98% → **−16.29%** |
| **`inverse-volatility-60`** | −2.03% → **−2.04%** |

**低波動幾乎不受影響（−0.01pp），動能掉了 90pp。**

因為**修正的傷害正比於策略持有多少會跳空的股票**——動能持有近期強勢股，而低波動持有的正好是不跳空的那些。

**窗口腰斬本身也是結果**：修正後動能更早耗盡而停止交易，共同窗口因此由 2024-09-16 提前到 2022-06-21。

### 5.3 這個反轉能主張什麼、不能主張什麼

**能：** 在修正後的同一個 568 場次窗口內，**低波動的報酬高於動能**（−2.04% 對 −16.29%）。

**不能：** 拿修正前的 1,114 場次去比修正後的 568 場次。**窗口不同就不是同一個問題。**

而[比較 001](m7-comparison-001-result-2026-08-28.md) 的結論是「兩個候選誰都沒有勝出」——**方向反轉不推翻「誰都沒贏」**，因為兩邊在修正後都是負報酬。

## 6. 一個貫串全部四份的性質

**修正的傷害與「持有的股票會不會跳空」成正比：**

| 對象 | 受傷程度 |
|---|---|
| 移動停損（停損貼著價格）| **最重**，−62pp |
| 動能（持有近期強勢股）| **重**，−90pp（比較 005）|
| 固定停損 | 中，−27 至 −43pp |
| **低波動（持有不跳空的股票）** | **幾乎為零，−0.01pp** |

**這不是四個獨立的觀察，是同一件事的四個切面**，而它與[界限量測](m7-stop-fill-bound-2026-09-04.md)當時的預測一致：跳空頻率相近而代價差 5 到 600 倍。
