## 0. 這份文件取代了什麼

2026-08-29 至 2026-09-01 之間，`docs/evidence/broker/` 保存四個檔案：牌告 PDF 的原始位元組、它的文字擷取、它的 metadata，以及費率頁優惠的逐字轉錄。

**它們現在不在這個倉庫裡。**

原因不是它們錯了，也不是它們沒用。原因是它們合起來會回答一個這個專案不打算公開的問題：**這個帳戶開在哪一家券商、什麼時候開的、打算投入多少。** 那三件事單獨看都無害，湊在一起是一份個人理財側寫，而它與這個專案想證明的任何事情都無關。

## 1. 扣住之後，還剩下什麼可以被檢查

**條款本身完整保留**，因為它們是這個專案每一個成本數字的來源：

| 項目 | 值 | 證據狀態 |
|---|---:|---|
| 買賣手續費率 | 1.425‰（每側）| `publisher-archived-privately` |
| 最低手續費 | **每筆** NT$20 | `publisher-archived-privately` |
| 賣出證券交易稅 | 0.3% | 法定 |
| 折讓 | **無** | `publisher-archived-privately` |

以及那份文件**不含**什麼（這一半同樣重要，且是查證過而非假設的）：

- 不含 2026 優惠（沒有 2 折、沒有 NT$1 最低收費）
- 不含零股手續費規則
- 不含任何到期日
- **不含發布者自己的名字**

最後一項是這次扣住之所以代價較小的全部理由：**身分本來就不在文件裡，只在「去哪裡抓到它」這件事上。**

## 2. 代價，寫下來因為它是代價

原本的證據強度來自「原始位元組加雜湊，任何人都能重新檢查它有沒有被改過」。

**扣住原件之後，這句話對外人只剩一半。** 雜湊在上面，任何人都能對他自己取得的文件重算並比對——但**這份文件要去哪裡取得，這裡沒有說**。所以：

- 對 Owner：證據鏈完整，`tests/unit/test_broker_terms_provenance.py` 仍逐項驗證原件。
- 對外人：這些條款是**被陳述的**，不是可獨立驗證的。雜湊讓「這份文件後來被改過」可以被發現，但不讓「這份文件存在且說了這些」被證實。

**這是一次真實的證據降級，不是一次無損的整理。** 把它寫成 `publisher-archived-privately` 而不是繼續用 `publisher-archived-pdf`，就是為了讓這件事在型別上看得見。

不接受的替代方案：留著 PDF 但不提券商名。那不會有用——PDF 的來源 URL 就是身分本身，而拿掉 URL 之後留下的是一份沒有出處的 PDF，那比一個誠實的缺口更糟。

## 3. 這不改變任何既有結論

十六次試驗全部在牌告預設下跑過，數字沒有動。改變的只有一件事：**讀者能親自驗證到哪一步。**

M10 第一項阻擋在 [D20](m3-owner-decision-d20-2026-08-29.md) 已解除，且**不因本次改為不公開而回復**——阻擋問的是 Owner 有沒有取得並檢視文件，那件事發生過，而且發生在此之前。

## 4. 尚未關閉的項目

### 1. 兩支鏡像仍載有券商名

`m4/rules.py` 第 323、339 行的註解仍寫出券商名。它們沒有被改，因為 `m4/rules.py` 與 `m5/ledger.py` 是 Taiwan Core 的**逐位元鏡像**，`tests/invariant/test_upstream_parity.py` 在盯；只改這一側會打破鏡像。

2026-09-01 檢視時 Taiwan Core 的工作樹有未提交的變更，**因此沒有在那裡動手**——把一個無關的改動混進別人未完成的工作裡，是這個專案不做的事。

修法（Taiwan Core 工作樹乾淨時執行，兩側必須同一次改）：

```
src/tw_sepa_screener/market_rules.py 第 323、339 行：把券商名改為「The published schedule」
再把該檔複製回 m4/rules.py，跑 test_upstream_parity.py 確認雜湊相同
```

在那之前，`.github/workflows/ci.yml` 的券商名守門**明確排除**這兩個檔案。排除是具名的，不是靜默的——一個沒有人知道的例外會變成一個沒有人修的例外。

### 2. 歷史中仍可取得

券商名最早出現在 `96d74d4`，早於多份 evidence 文件所引用的 commit 雜湊。徹底清除需要改寫約三十個 commit，**那會使那些引用全部失效**——而可追溯的引用正是這個專案的核心資產。

**因此本次只把它從當前樹移除，不改寫歷史。** 這是一個知情的取捨：付出的是「翻 `git log -S` 的人查得到」，換回的是「每一份證據文件引用的雜湊都還指得到東西」。
