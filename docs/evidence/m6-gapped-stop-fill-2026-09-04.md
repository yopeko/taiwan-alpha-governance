# 停損不可能成交在當天沒有成交過的價格：修正後動能由 −4.62% 變成 −18.85%（2026-09-04）

| 欄位 | 值 |
|---|---|
| 日期 | 2026-09-04 |
| 起因 | Owner：「先完成日線級（開盤和收盤價），以後有需要再改成分鐘級」 |
| 變更 | `scripts/m6/run_ledger_backtest.py`，停損出場的成交價 |
| 性質 | **修正，不是重構。所有既有候選結果不再可比** |
| 試驗登錄 | #132，`probe`，`influenced_a_choice = false` |

## 0. 一句話

**模型讓每一筆停損都成交在停損價，而 21% 的場次開盤就已經在停損價之下——那個價格當天從來沒有成交過。**

修正後，同一組態的最終 NAV 由 142,800.12 降到 **121,500.30**，差 **期初 NAV 的 14.23%**。

## 1. 停損單是觸發，不是限價

一旦價格觸及停損，委託變成**市價單**，所以成交價是市場接下來給的價格。

**開盤就已經在停損價之下時，觸發發生在任何人能反應之前，第一個可得的價格是開盤價。**

```python
reason = "stop"
price = min(position.stop_price, opened)     # 原本是 position.stop_price
```

`min` 只往一個方向動——**新規則不可能比舊的好**，它的上界就是舊行為。一條測試盯著這件事，因為一個「可能讓成交比停損價更好」的改動，會是把優勢憑空送給帳戶。

## 2. 這件事是怎麼被找到的

Owner 問「做成 XQ 那種但加分鐘級進出場，距離多遠」。建議的第一步是先確認值不值得，而[那一步](m7-stop-fill-bound-2026-09-04.md)不必買資料——**真正的成交價必須落在當日高低區間內，而區間已經在倉庫裡**。

夾出來的結果：即使**每一筆停損都成交在當時可能的最好價格**，模型仍樂觀 **6.23% 的期初 NAV**，因為 21.0% 的停損跳空。

**那是下限，不是估計。** 而修它只需要開盤價。

## 3. 影響

同一組態：`momentum-12-1`、breakout 進場、`lookback=20`、`stop_pct=0.08`、參考衡量規模 149,717、參與率 0.01、全窗口 1,862 場次。

| | 修正前 | 修正後 | |
|---|---:|---:|---|
| 最終 NAV | 142,800.12 | **121,500.30** | **−21,299.82** |
| 報酬 | −4.62% | **−18.85%** | −14.23pp |
| 已實現損益 | 95,872.68 | **49,432.78** | −46,439.90 |
| **最大回撤** | 65.59% | **51.57%** | **−14.02pp** |
| 完成交易 | 1,221 | 1,176 | −45 |
| 停損筆數 | 690 | 679 | −11 |

**差額是期初 NAV 的 14.23%。**

### 3.1 為什麼比第 0 步夾出的 6.23% 大

**兩者不是同一次執行。** 第 0 步量的是 `tw-alpha-m7-halts-002` 的動能臂，**205 筆停損**；本次是全窗口 breakout 組態，**690 筆停損**，超過三倍。

**6.23% 是那一次執行的下限，不是這一次的預測。**

### 3.2 最大回撤反而變小，而那不是好消息

65.59% → 51.57%。

**這是複利路徑的差異，不是風險改善。** 成交價變差使帳戶較早變小，後續部位隨之變小，於是後面的絕對虧損變小，而相對於一個較低的高水位算出來的百分比也變小。

**不要把它讀成「修正之後策略比較安全」。** 同一份帳戶在同一段市況下賺得更少，回撤的分母也更小。

## 4. 所有既有候選結果不再可比

候選 003、005、006、對照 001、診斷 002／003／004 **全部是在樂觀的成交模型下跑出來的**。

**那些結論本身多半不受影響**——它們是「沒有通過」，而修正只會讓表現更差，不會把不通過變成通過。但：

- **數字不能再與新的執行並排**
- [對照 001](m7-control-001-result-2026-09-01.md) 的「動能勝過 20/20 隨機種子」**方向可能仍成立但幅度未知**：本文件 §0 的量測顯示動能的跳空代價是隨機組的 5 到 600 倍，**所以修正對動能的傷害大於對隨機組**
- [診斷 004](m7-diagnostic-004-reachability-result-2026-09-02.md) 的「十四格全部在 8% 之上」**只會更加成立**

**沒有重跑任何既有候選。** 重跑是一次決定與一批試驗登錄，不是這次修正的一部分。本文件把不可比這件事寫下來，而不是讓它靜默發生。

## 5. 守門

`tests/unit/test_gapped_stop_fill.py`，10 條，皆不讀本機資料：

- 跳空成交在開盤價、未跳空成交在停損價、開盤恰等於停損成交在停損價
- **新規則不可能優於舊規則**（`min` 的單向性）
- **缺開盤價時退回收盤價，不是退回停損價**——那會讓罕見情況悄悄恢復樂觀行為
- **出場理由仍是 `stop`**，改名會讓每一份數停損的報告失效
- **量到的數字寫在修正旁邊**——一個沒有數字的正確性改動是一種偏好
- **舊表達式不得以任何形式殘留**

## 6. 沒有做的

- **沒有動進場。** 進場已經用次一場次的開盤價。
- **沒有動其他出場理由。** `max-holding` 與 `left-the-top-n` 仍用收盤價，那兩者不是觸發式的——它們在收盤後才知道要出場。
- **沒有處理漲跌停鎖死。** 跌停鎖死時開盤價也可能成交不到，那需要逐筆或委託簿資料，日線答不了。
- **沒有重跑既有候選**（§4）。
