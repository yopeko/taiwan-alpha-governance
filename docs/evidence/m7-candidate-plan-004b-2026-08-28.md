# 候選計畫 004b：拿掉我自己加的兩個夾子（2026-08-28）

**狀態：`planned`。取代[計畫 004](m7-candidate-plan-004-2026-08-28.md)，而 004 已提交、從未執行。**

Owner 於 2026-08-28 裁決選項乙：判定為**執行前發現的規格缺陷**，改寫計畫，乘數不動。

## 0. 004 為什麼沒有執行

004 把停損定為 `2 × 60日波動 × √21`，**夾在 4%–16%**。

在跑任何回測之前量了開發區的實際分布（118,079 個樣本）：

| | 夾住後 |
|---|---:|
| 中位數 | **16.00%，就是上限** |
| 夾在上限 | **59.3%** |
| 夾在下限 | 1.4% |
| 落在中間 | 39.3% |

**六成的證券拿到的是一個常數，只是常數從 8% 換成 16%。** 而動能排序偏好高波動股，被選進前十名的幾乎都會落在被夾住的那一群——最後會是全部 4.7% NAV 的等權，只是更小。

那樣的結果會**來自曝險被砍半，而不是來自波動縮放**，且無法歸因。而歸因正是這個候選要驗的東西。

### 這是計畫寫作上的第二次同類錯誤

[計畫 003](m7-candidate-plan-003-2026-08-28.md) 把可否證預期對著錯的基準寫（用了 M6.2 另一個設計的週轉率）。

004 則是**寫了一個沒有先看過經驗分布的規則**——4%–16% 憑印象定，而台股 60 日波動讓中位數落在 18.51%，遠在上限之外。

## 1. 改動：移除兩個邊界，其餘完全不動

| | 004 | **004b** |
|---|---|---|
| 停損 | `2 × 60日波動 × √21`，夾 4%–16% | `2 × 60日波動 × √21`，**不夾** |
| 乘數 2 | 不動 | **不動** |
| 排序 | `momentum-12-1` | 不動 |
| 進場 | rank-only，每 21 場次前 10 | 不動 |
| 對照 | 固定 8% 停損 | 不動 |

**自由參數由 2 個變成 0 個。** 移除是減少，不是增加。

### 為什麼夾子本來就多餘

004 加夾子的理由是「防退化」，而同一段話裡寫著「**兩端都在契約既有的上限之內**」——那正是它們多餘的證明。

實測未夾住時 `plan_position` 的行為：

| 停損距離 | 部位佔 NAV | 結果 |
|---:|---:|---|
| 0.01% | — | **拒絕：`round-trip-cost-exceeds-planned-risk`** |
| 1% | 33.40% | 通過所有上限 |
| 6.27%（P05）| 11.96% | 通過 |
| 18.51%（中位）| 4.04% | 通過 |
| 41.19%（P95）| 1.80% | 通過 |

安靜的那一端由**成本閘門**接住——一個風險預算比它的來回成本還小的部位被拒絕，而那是正確的理由。（004 的說法是「45% 權重上限接住」，實測顯示不是；已在程式註解中更正。）

吵雜的那一端不需要接住，它只是變小。

## 2. 這次沒有可否證的預期，而理由要寫下來

004 的預期是「部位大小最大最小比值至少 2 倍」。

**那個預期已經被上面那次事前檢查消耗掉了**——我現在知道分布是 P05 11.96%、中位 4.04%、P95 1.80%，比值遠超過 2 倍。它不再是預測。

**而現在臨時想一個新的預期，等於在看過相關資料之後才寫下它**，那與沒有預期一樣沒有價值，只是看起來比較好。

所以本計畫**明確不設可否證預期**，並把這件事記為代價：事前檢查買到了一個不會被誤導的執行，賣掉的是一次預測的機會。

## 3. 什麼結果會被算作「沒有幫助」

**與計畫 001、003、004 完全相同**，判定只看參考衡量規模：

1. 兩個參與率下，B 的窗口內報酬皆高於 A；且
2. 差距皆至少 **5 個百分點**；且
3. B 的窗口內最大回撤不高於 A 的 **1.5 倍**。

四份計畫用同一組門檻，讓「通過」在候選之間可比。

**另記一項不參與判定但必須呈報**：實際持有部位的大小分布，以及總曝險。中位停損 18.51% 對應部位 4.04%，遠小於固定停損的 9.35%——**若 B 表現較好，必須能分辨那是波動縮放還是單純曝險較低**，而這一欄是分辨的依據。

## 4. 排序仍用動能，理由不變

一次只換一個東西；且**動能是對這個機制最不利的測試**——若停損改變能讓一個排序能力為零（[量測 001](rank-quality-001-2026-08-28.md)：IC 命中率 48.2%、逐年符號翻轉）的候選變好，那個改善確定來自權重而不是選股。
